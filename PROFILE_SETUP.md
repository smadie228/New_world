# Что ещё настроить на GitHub

Подключение GitHub не позволяет мне создать новый репозиторий или менять общие настройки профиля. Эти шаги выполняются в интерфейсе GitHub.

1. Создать **публичный** репозиторий с точным названием **smadie228**. GitHub автоматически покажет его README на главной странице профиля.
2. Перенести туда содержание README.md из New_world.
3. Profile → Edit profile: Name = Danil Chernikov; Bio = Junior IT Support / Linux | Python, Bash, SSH | Learning troubleshooting; Location = Moscow (необязательно).
4. Profile → Customize your pins: закрепить Service Checker, New_world, push_swap, synergy-functional-programming.
5. При желании переименовать репозиторий **sub** в **service-checker** через Settings → General → Repository name. После переименования заменить ссылку в README.
6. При желании создать отдельный репозиторий **linux-incident-lab** и перенести в него одноимённую папку из New_world.
